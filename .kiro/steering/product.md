# Product Overview

This is a personal resume website built as a React single-page application. The site displays professional information including:

- About section with personal summary and location
- Skills showcase with tag-based display
- Professional experience with detailed role descriptions
- Certifications with links to verification
- Education background
- Contact information

The resume data is driven by a JSON configuration file (`src/resumeData.json`), making it easy to update content without code changes. The site features a responsive design with a sidebar navigation and smooth scrolling between sections.

Key features:
- Data-driven content from JSON configuration
- Responsive sidebar navigation
- Smooth scroll-to-top functionality
- Multiple display variants for different content types (tags, cards, experience)
- Clean, professional styling
